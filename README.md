# 🛒 powerbi-blinkit-project
power BI dashboard analyzing Blinkit sales performance with key metrics and visual insights.

## 📌 Project Overview
This project is a *Power BI Dashboard* built on Blinkit Sales Data.  
It helps to analyze sales performance, outlet types, fat content, item types, and customer ratings.

---

## 📊 Key Insights
- *Total Sales:* $1.20M  
- *No. of Items:* 8523  
- *Average Sales:* $141  
- *Average Rating:* 3.9 ⭐  

---

## 📈 Dashboard Features
1. *Sales Overview*
   - Total Sales, Average Sales, and Ratings
   - Number of items sold

2. *Outlet Analysis*
   - Sales by Outlet Size (Small, Medium, High)
   - Sales by Outlet Location (Tier 1, Tier 2, Tier 3)
   - Sales by Outlet Type

3. *Item Analysis*
   - Sales by Item Type (Fruits, Snacks, Household, etc.)
   - Sales by Fat Content (Low Fat vs Regular)

4. *Yearly Trend*
   - Outlet establishment and sales growth over years
